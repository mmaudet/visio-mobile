# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| Latest release | Yes |
| Older versions | No |

## Reporting a vulnerability

If you discover a security vulnerability, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, email **mmaudet@linagora.com** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You will receive a response within 48 hours. We will work with you to
understand and address the issue before any public disclosure.

## Scope

This policy applies to the Visio Mobile codebase:

- Rust crates (`visio-core`, `visio-ffi`, `visio-video`, `visio-desktop`)
- Android app (`android/`)
- iOS app (`ios/`)
- Desktop frontend (`crates/visio-desktop/frontend/`)

For vulnerabilities in LiveKit itself, please report to the
[LiveKit security team](https://github.com/livekit/livekit/security/policy).
