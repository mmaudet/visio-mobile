# v0.9.0 Phase 4 — Smart Subscriptions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reduce video bandwidth by unsubscribing off-screen participants and keeping screen share always at HIGH quality. Target: -72% bandwidth with 20 participants.

**Architecture:** New `SubscriptionManager` in visio-core, orchestrated by RoomManager. Combines LayoutEngine visibility info + BandwidthController mode to decide per-track subscription and quality. Anti-jitter delays prevent subscribe/unsubscribe thrashing during swipe. All platforms (mobile + desktop) benefit automatically since the logic is in the core.

**Tech Stack:** Rust (visio-core), LiveKit SDK 0.7.32 (`RemoteTrackPublication` API)

**Spec:** `docs/superpowers/specs/2026-04-04-v0.9.0-release-design.md` — Phase 4 section

**Prerequisite:** Phase 2 (LayoutEngine) and Phase 3 (pagination providing visible_participants) must be merged.

```rust
//! Video subscription manager.
//!
//! Decides per-track video quality based on visibility (from LayoutEngine)
//! and bandwidth mode (from BandwidthController).

use crate::bandwidth::BandwidthMode;
use std::collections::HashMap;
use std::time::{Duration, Instant};

#[derive(Debug, Clone, Copy, PartialEq)]
pub enum VideoQuality {
    High,
    Low,
    Off,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub enum TrackVisibility {
    Visible,
    Precached,
    OffScreen,
}

/// Compute the desired quality for a camera track.
pub fn desired_quality(visibility: TrackVisibility, bandwidth: BandwidthMode) -> VideoQuality {
    match (visibility, bandwidth) {
        (_, BandwidthMode::AudioOnly) => VideoQuality::Off,
        (TrackVisibility::Visible, BandwidthMode::Full) => VideoQuality::High,
        (TrackVisibility::Visible, BandwidthMode::ReducedVideo) => VideoQuality::Low,
        (TrackVisibility::Precached, BandwidthMode::Full) => VideoQuality::Low,
        (TrackVisibility::Precached, BandwidthMode::ReducedVideo) => VideoQuality::Off,
        (TrackVisibility::OffScreen, _) => VideoQuality::Off,
    }
}

/// Compute the desired quality for a screen share track.
pub fn desired_screen_share_quality(bandwidth: BandwidthMode) -> VideoQuality {
    match bandwidth {
        BandwidthMode::AudioOnly => VideoQuality::Off,
        _ => VideoQuality::High,
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_decision_matrix_full_mode() {
        assert_eq!(desired_quality(TrackVisibility::Visible, BandwidthMode::Full), VideoQuality::High);
        assert_eq!(desired_quality(TrackVisibility::Precached, BandwidthMode::Full), VideoQuality::Low);
        assert_eq!(desired_quality(TrackVisibility::OffScreen, BandwidthMode::Full), VideoQuality::Off);
    }

    #[test]
    fn test_decision_matrix_reduced_mode() {
        assert_eq!(desired_quality(TrackVisibility::Visible, BandwidthMode::ReducedVideo), VideoQuality::Low);
        assert_eq!(desired_quality(TrackVisibility::Precached, BandwidthMode::ReducedVideo), VideoQuality::Off);
        assert_eq!(desired_quality(TrackVisibility::OffScreen, BandwidthMode::ReducedVideo), VideoQuality::Off);
    }

    #[test]
    fn test_decision_matrix_audio_only() {
        assert_eq!(desired_quality(TrackVisibility::Visible, BandwidthMode::AudioOnly), VideoQuality::Off);
        assert_eq!(desired_quality(TrackVisibility::Precached, BandwidthMode::AudioOnly), VideoQuality::Off);
        assert_eq!(desired_quality(TrackVisibility::OffScreen, BandwidthMode::AudioOnly), VideoQuality::Off);
    }

    #[test]
    fn test_screen_share_always_high() {
        assert_eq!(desired_screen_share_quality(BandwidthMode::Full), VideoQuality::High);
        assert_eq!(desired_screen_share_quality(BandwidthMode::ReducedVideo), VideoQuality::High);
        assert_eq!(desired_screen_share_quality(BandwidthMode::AudioOnly), VideoQuality::Off);
    }
}
```

```rust
    fn test_unsubscribe_delay() {
        let mut mgr = SubscriptionManager::new();
        let now = Instant::now();

        // Track is currently subscribed HIGH
        mgr.apply_current("track_1", VideoQuality::High);

        // Request unsubscribe
        mgr.request_change("track_1", VideoQuality::Off, now);

        let actions = mgr.pending_actions(now + Duration::from_millis(1500));
        assert!(actions.is_empty());

        // At 2.1s: unsubscribe fires
        let actions = mgr.pending_actions(now + Duration::from_millis(2100));
        assert_eq!(actions.len(), 1);
        assert_eq!(actions[0], ("track_1".to_string(), VideoQuality::Off));
    }

    #[test]
    fn test_unsubscribe_cancelled_by_resubscribe() {
        let mut mgr = SubscriptionManager::new();
        let now = Instant::now();

        mgr.apply_current("track_1", VideoQuality::High);
        mgr.request_change("track_1", VideoQuality::Off, now);

        // At 1s: resubscribe (user swiped back)
        mgr.request_change("track_1", VideoQuality::High, now + Duration::from_secs(1));

        // At 2.1s: no action (cancelled)
```

```rust
const UNSUBSCRIBE_DELAY: Duration = Duration::from_secs(2);
const QUALITY_DOWNGRADE_DELAY: Duration = Duration::from_secs(5);

pub struct SubscriptionManager {
    /// Current actual state of each track
    current: HashMap<String, VideoQuality>,
    /// Pending changes: track_sid → (target quality, request time)
    pending: HashMap<String, (VideoQuality, Instant)>,
}

impl SubscriptionManager {
    pub fn new() -> Self {
        Self {
            current: HashMap::new(),
            pending: HashMap::new(),
        }
    }

    /// Record the current actual quality of a track.
    pub fn apply_current(&mut self, track_sid: &str, quality: VideoQuality) {
        self.current.insert(track_sid.to_string(), quality);
        // Clear any pending change for this track
        self.pending.remove(track_sid);
    }

    /// Request a quality change. May be delayed or immediate.
    pub fn request_change(&mut self, track_sid: &str, target: VideoQuality, now: Instant) {
        let current = self.current.get(track_sid).copied().unwrap_or(VideoQuality::Off);

        if current == target {
            self.pending.remove(track_sid);
            return;
        }

        // Upgrade (Off→Low, Off→High, Low→High): immediate
        if Self::is_upgrade(current, target) {
            self.pending.insert(track_sid.to_string(), (target, now));
            return;
        }

        // Downgrade: delayed
        self.pending.insert(track_sid.to_string(), (target, now));
    }

    /// Returns actions whose delay has elapsed. Removes them from pending.
    pub fn pending_actions(&mut self, now: Instant) -> Vec<(String, VideoQuality)> {
        let mut ready = Vec::new();

        self.pending.retain(|track_sid, (target, requested_at)| {
            let current = self.current.get(track_sid).copied().unwrap_or(VideoQuality::Off);
            let delay = if Self::is_upgrade(current, *target) {
                Duration::ZERO // immediate
            } else if *target == VideoQuality::Off {
                UNSUBSCRIBE_DELAY
            } else {
                QUALITY_DOWNGRADE_DELAY
            };

            if now.duration_since(*requested_at) >= delay {
                ready.push((track_sid.clone(), *target));
                false // remove from pending
            } else {
                true // keep pending
            }
        });

        // Apply the ready actions to current state
        for (ref sid, quality) in &ready {
            self.current.insert(sid.clone(), *quality);
        }

        ready
    }

    /// Stats for monitoring.
    pub fn stats(&self) -> SubscriptionStats {
        let mut high = 0u32;
        let mut low = 0u32;
        let mut off = 0u32;
        for quality in self.current.values() {
            match quality {
                VideoQuality::High => high += 1,
                VideoQuality::Low => low += 1,
                VideoQuality::Off => off += 1,
            }
        }
        SubscriptionStats {
            subscribed_high: high,
            subscribed_low: low,
            unsubscribed: off,
            screen_shares: 0, // Caller sets this
        }
    }

    fn is_upgrade(from: VideoQuality, to: VideoQuality) -> bool {
        matches!(
            (from, to),
            (VideoQuality::Off, VideoQuality::Low)
            | (VideoQuality::Off, VideoQuality::High)
            | (VideoQuality::Low, VideoQuality::High)
        )
    }
}

#[derive(Debug, Clone)]
pub struct SubscriptionStats {
    pub subscribed_high: u32,
    pub subscribed_low: u32,
    pub unsubscribed: u32,
    pub screen_shares: u32,
}
```

```rust
fn compute_subscriptions(&self) {
    let layout = &self.layout;
    let bandwidth_mode = self.bandwidth.lock().unwrap().mode();
    let visible = layout.visible_participants();
    let precached = layout.precached_participants();

    let mut sub_mgr = self.subscriptions.lock().unwrap();
    let now = std::time::Instant::now();

    // For each known remote video track, compute desired quality
    let tracks = self.subscribed_tracks.blocking_lock(); // or use the appropriate lock
    for (track_sid, track) in tracks.iter() {
        let participant_sid = &track.participant_sid;
        let is_screen_share = track.source == TrackSource::ScreenShare;

        let desired = if is_screen_share {
            subscriptions::desired_screen_share_quality(bandwidth_mode)
        } else {
            let visibility = if visible.contains(participant_sid) {
                subscriptions::TrackVisibility::Visible
            } else if precached.contains(participant_sid) {
                subscriptions::TrackVisibility::Precached
            } else {
                subscriptions::TrackVisibility::OffScreen
            };
            subscriptions::desired_quality(visibility, bandwidth_mode)
        };

        sub_mgr.request_change(track_sid, desired, now);
    }
}
```

```rust
async fn apply_track_quality(&self, track_sid: &str, quality: VideoQuality) {
    if let Some(room) = self.room_ref.lock().await.as_ref() {
        for (_, participant) in room.remote_participants() {
            for (_, publication) in participant.track_publications() {
                if publication.sid().as_str() == track_sid {
                    match quality {
                        VideoQuality::Off => {
                            publication.set_subscribed(false);
                        }
                        VideoQuality::High => {
                            publication.set_subscribed(true);
                            // set_video_quality if available in SDK
                        }
                        VideoQuality::Low => {
                            publication.set_subscribed(true);
                            // set_video_quality to LOW if available
                        }
                    }
                }
            }
        }
    }
}
```
